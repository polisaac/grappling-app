# Sistema de Diseño y Estética (Inspired by X & Martial Arts)

## 1. Paleta de Colores
- **Modo Oscuro Predeterminado (High Contrast):**
  - **Fondo Principal (`background`):** `#000000` (Negro puro estilo X)
  - **Fondo Superficie/Tarjetas (`surface`):** `#16181C` (Gris oscuro para bloques e inputs)
  - **Bordear/Divisores (`border`):** `#2F3336` (Líneas sutiles de 1px)

- **Colores de Acento (Judo/BJJ & X Blue):**
  - **Primario / Acción (`primary`):** `#1D9BF0` (Azul eléctrico X / Cinturón Azul)
  - **Texto Principal (`text-main`):** `#E7E9EA` (Blanco suave de alto contraste)
  - **Texto Secundario (`text-muted`):** `#71767B` (Gris neutro para labels y fechas)
  - **Éxito / Nodos Positivos:** `#00BA7C` (Verde X)
  - **Error / Nodos Fallidos:** `#F4212E` (Rojo X)

- **Acentos de Grado (Rangos Grappling):**
  - **White Belt:** `#FFFFFF`
  - **Blue Belt:** `#1D9BF0`
  - **Purple Belt:** `#7928CA`
  - **Brown Belt:** `#8B4513`
  - **Black Belt:** `#16181C` con acento rojo `#E50914`

## 2. Tipografía (Estilo X / Chirp)
- **Familia:** System Sans-Serif (`SF Pro Display` en iOS, `Roboto` en Android, o `Inter`).
- **Jerarquía:**
  - **Títulos (`H1`, `H2`):** Bold (700) u Heavy (800), alineados a la izquierda, sin serifas.
  - **Botones y CTAs:** Bold (700) o Semibold (600), todo texto legible.
  - **Cuerpo / Inputs:** Regular (400), tamaño base 15px con interlineado holgado.

## 3. Componentes Visuales y Layout
- **Botones:** Formato píldora redondeada (`borderRadius: 9999px`), estilo X.
- **Inputs:** Fondo `#16181C`, borde de 1px `#2F3336`. Al enfocar, el borde cambia a `#1D9BF0`.
- **Tarjetas / Muro:** Contenedores planos sin sombras excesivas, divididos por bordes inferiores horizontales de 1px (`#2F3336`).
